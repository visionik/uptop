# Plugin Gallery

Community-contributed plugins for uptop. If you've built a plugin, open a PR to add it here.

## Official Examples

These example plugins are planned for future releases:

| Plugin | Type | Description |
|--------|------|-------------|
| Hello World | Pane | Minimal example demonstrating the plugin API |
| Docker | Pane | Container monitoring (list, CPU, memory per container) |
| Weather | Pane | Weather conditions from an external API |
| Log Monitor | Pane | Tail and monitor log files |

## Submitting Your Plugin

1. Publish your plugin as a Python package (e.g., `uptop-plugin-yourname`)
2. Ensure it follows the [quality standards](contributing.md#plugin-quality-standards)
3. Open a pull request to add it to this page with:
   - Plugin name and link
   - Plugin type (Pane, Collector, Formatter, Action)
   - Brief description
   - Installation instructions
